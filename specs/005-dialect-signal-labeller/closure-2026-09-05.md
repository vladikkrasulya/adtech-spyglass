## T026 — shared-model health decision

**No extra application health dependency is needed.** The model is optional assistance: deterministic
analysis and the manual builder continue without it. On the fallback path, `verifyPersona()` checks
the local runner and model tag before generation; unavailable/missing model returns a named 503,
and generation failures/timeouts return 502/504. `lib/http.js:sendError()` routes 5xx responses to
the existing rate-limited operator notification path. The browser keeps the manual builder route.
The main `/api/health` should continue reporting the mandatory DB readiness, not fail the entire
application because optional assistance is unavailable. This is the explicit no-change decision
allowed by T026; it does not add synthetic alert traffic or change monitoring configuration.
