# Closure contract

- Resource identity covers the bytes actually returned, all rewritten dependencies and coupled template/style resources. Old-version failure is explicit, non-cacheable and recoverable without forced reload or lost input.
- A selection enhancement preserves its source select, emits the existing change contract once and restores/cleans up on unmount. Keyboard navigation, naming, disabled options, pointer/touch, dynamic options and multiple synchronized controls are tested.
- Unlock credentials belong to one form and one submission path. Username is escaped and scoped; no new credential endpoint or persistence.
- All three email entry points have independent observable locale tests. Event-log checks exercise the current ClickHouse transport and privacy contracts; retired SQLite skips are replaced with active synthetic tests.
- Dependency guard rejects downgraded or unsupported ranges/locked versions and preserves known advisory predicates; full and production audits are recorded separately.
- Release records point to verified immutable tags and exact corresponding changelog sections.
- Local preservation precedes cleanup; no private content enters tracked evidence and no unique draft is dropped merely because it is old.
- Retain the existing repository, local package and monitoring baseline under the stated maintenance assumption unless the owner supplies a different choice. Renaming, first publication or new monitoring destinations require that specific choice. Future product work remains a separate plan; existing cancelled research stays closed.
- Complete local and hosted gates, fresh canonical pre-deploy backup and exact-SHA deployment/readback remain mandatory.

- Admin source links grant only HTTP(S) navigation. Promotion validates persisted state, supported locale/category and canonical route slug before any file/status side effects. Exclusive creation prevents collision overwrite; serialized scalar metadata cannot inject fields or opt into indexing. Public API and SSR readers agree on the resulting scalar values.
